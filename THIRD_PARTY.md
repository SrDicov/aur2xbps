## Git submodules

- `common/void-packages` — [void-linux/void-packages](https://github.com/void-linux/void-packages),
  BSD-2-Clause. Used read-only for `common/shlibs` (SONAME → package mapping).
  No source files are copied into this repository.

## Data files

- `tests/fixtures/srcinfo/*.SRCINFO` — real metadata snapshots from the
  [Arch User Repository](https://aur.archlinux.org). `.SRCINFO` files are
  machine-generated factual metadata of the respective upstream packages.
  They are included solely as parser test fixtures; no PKGBUILD code is
  redistributed. Synthetic malicious fixtures (`atomic-lockfile`, `js-digest`,
  `lockfile-js`) were written by this project for regression testing of the
  supply-chain filter.
- `src/common/arch_to_nix_repology.json` — mapping table generated by
  `scripts/repology-sync.py` from queries to the public Repology API v1 plus a
  hand-maintained table. Repology API responses are factual package-name
  correspondences; the aggregation script and manual entries are part of this
  project under GPL-3.0-or-later. See https://repology.org for API terms.

## Templates generated at runtime

Generated Nix flakes reference nixpkgs (MIT) pinned via `flake.lock`. Generated
XBPS packages embed upstream software whose licenses vary per package; aur2xbps
never redistributes such binaries — users build them locally from original
sources. Packages with non-redistributable licenses are flagged `restricted=yes`
in their templates.
